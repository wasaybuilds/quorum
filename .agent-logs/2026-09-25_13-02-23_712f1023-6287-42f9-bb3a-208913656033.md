## WHAT YOU'RE BUILDING
 
**Quorum** - A rebuild of Fathom.video for the 8x take-home.
 
Fathom is an AI meeting assistant that:
1. Records meetings (Zoom, Google Meet, Teams)
2. Transcribes them with high accuracy
3. Generates AI summaries (executive summary, key points, decisions, concerns)
4. Extracts action items with owners and due dates
5. Lets you search across meeting history
6. Has "Ask Fathom" - a ChatGPT-style interface to query meetings
7. Syncs insights to CRM/productivity tools
**Core Value:** Turn meetings into searchable, actionable intelligence without manual note-taking. Saves 38 minutes per meeting on average.
 
**What Fathom Users Love:**
- Accurate transcription (handles accents, crosstalk, multiple speakers)
- Instant AI summaries with customizable templates
- Ask Fathom can search entire meeting history
- One-click highlights during calls
- Clip sharing for key moments
- CRM/Slack/Asana integrations
- Bot-free capture option (no visible participant)
- Desktop app + mobile
- Desktop widget with meeting alerts

## AI INTEGRATION (Server-Side Only)
 
**NEVER expose API key to browser.**
 
Pattern:
```
Client sends POST request
→ Next.js API route
→ Calls Anthropic API with ANTHROPIC_API_KEY
→ Anthropic responds
→ Server returns structured JSON
→ Client displays result
```
 
### API Endpoints
 
**POST /api/ai/analyze-meeting**
```
Input:
{
  transcript: Array<{ speaker, timestamp, text }>,
  title: string,
  participants: string[]
}
 
Output:
{
  executive_summary: string,
  key_points: string[],
  decisions: string[],
  concerns: string[],
  action_items: Array<{ task, owner, dueDate, priority }>
}
```
 
**POST /api/ai/ask-meeting**
```
Input:
{
  meetingId: string,
  question: string,
  transcript: Array<{ ... }>,
  summary: { ... }
}
 
Output:
{
  answer: string,
  sources: Array<{
    timestamp: number,
    speaker: string,
    text: string
  }>,
  confidence: 'high' | 'medium' | 'low'
}
```
 
**POST /api/ai/ask-multi-meeting**
```
Input:
{
  question: string,
  meetings: Array<{ id, title, transcript, summary }>
}
 
Output:
{
  answer: string,
  sources: Array<{
    meetingId: string,
    meetingTitle: string,
    timestamp: number,
    excerpt: string
  }>,
  patterns?: string[]
}
```

## AI INTEGRATION (Server-Side Only)
 
**NEVER expose API key to browser.**
 
Pattern:
```
Client sends POST request
→ Next.js API route
→ Calls Anthropic API with ANTHROPIC_API_KEY
→ Anthropic responds
→ Server returns structured JSON
→ Client displays result
```
 
### API Endpoints
 
**POST /api/ai/analyze-meeting**
```
Input:
{
  transcript: Array<{ speaker, timestamp, text }>,
  title: string,
  participants: string[]
}
 
Output:
{
  executive_summary: string,
  key_points: string[],
  decisions: string[],
  concerns: string[],
  action_items: Array<{ task, owner, dueDate, priority }>
}
```
 
**POST /api/ai/ask-meeting**
```
Input:
{
  meetingId: string,
  question: string,
  transcript: Array<{ ... }>,
  summary: { ... }
}
 
Output:
{
  answer: string,
  sources: Array<{
    timestamp: number,
    speaker: string,
    text: string
  }>,
  confidence: 'high' | 'medium' | 'low'
}
```
 
**POST /api/ai/ask-multi-meeting**
```
Input:
{
  question: string,
  meetings: Array<{ id, title, transcript, summary }>
}
 
Output:
{
  answer: string,
  sources: Array<{
    meetingId: string,
    meetingTitle: string,
    timestamp: number,
    excerpt: string
  }>,
  patterns?: string[]
}
```
